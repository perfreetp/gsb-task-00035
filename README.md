# 多工序制造车间实时排产模拟

纯前端单页应用，无需构建，直接用浏览器打开 `index.html` 即可（或 `python3 -m http.server` 后访问）。

## 场景

- 每个订单需依次经过 **切割 → 加工 → 质检 → 包装** 四道工序（含返工插入）。
- 8 台设备产能不同、可执行工序不同（如切割机 B 速度 ×1.4，质检台不具备加工能力）。
- 工序块之间的虚线表示**前后依赖**，红色虚线表示所属订单已延期。

## 功能

- **依赖感知排产引擎**：按各机台队列顺序串行排产，严格满足工序前后依赖、物料到货时间、设备故障停机窗口，杜绝同一机台时间冲突。
- **手动调整**：拖拽工序块更换机台/调整队内位置；点击工序块在右侧面板换机台、队首/前移/后移/队尾；订单列表可一键"置顶"。
- **扰动事件**：🚨 紧急插单、🔧 设备故障、🔁 质检返工、📦 物料延迟，运行中随时触发并自动重排。
- **实时风险检测**：机台能力冲突（无此工序能力标红并阻塞）、设备故障顺延、物料未到货、订单延期风险（预计完工 > 交期）。
- **调整影响对比**：每次调整后，订单列表实时显示每个订单**提前/推迟**多少，事件日志与风险面板汇总本次影响。
- **模拟时钟**：开始/暂停、1x/4x/10x 变速，工序随时间推进开工/完工。

## 文件
